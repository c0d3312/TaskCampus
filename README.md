# TaskCampus

Proyecto desarrollado para el Laboratorio de Desarrollo de Aplicaciones Web utilizando React y Vite. Consiste en una plataforma de gestion de tareas que integra operaciones CRUD, manejo de estado y conexion a una API externa simulada.

## Entorno de Desarrollo
- Node.js
- npm 
- React + Vite

## Instrucciones de Instalacion y Ejecucion

1. Abrir una terminal en la raiz del proyecto e instalar las dependencias:
   ```bash
   npm install
2. Iniciar el servidor:
   npm run dev
3. Acceder desde el localhost
